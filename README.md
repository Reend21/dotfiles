# dotfiles
Mine personal dotfiles for general apps and configs. It includes:
- Kitty config
- Fish config + plugins + fisher
- Librewolf and Vscodium extensions list
- easyeffects effect list
- both native (zypper) and flatpak app list
- fastfetch config
- librewolf user.js
- **install.sh** file to install everything automatically.

# usage
```
git clone https://github.com/Reend21/dotfiles
cd dotfiles
sudo chmod + x install.sh
./install.sh
```
